# 老师个人主页

网站采用中英文两份独立的静态 HTML，通过右上角的链接切换。保存后即可使用，无需构建、翻译 API 或后端。

## 文件结构

```text
teacher-homepage/
├── index.html          中文主页
├── en/
│   └── index.html      英文主页
└── static/
    ├── css/style.css   两页共用的样式
    ├── js/main.js      主题切换和视频播放
    ├── js/theme-init.js 首屏主题、系统主题监听与偏好保存
    └── images/         头像和四篇论文的 GIF 动图
```

## 修改与预览

- 中文内容直接修改 `index.html`，英文内容直接修改 `en/index.html`。内容更新时分别维护两份文案。
- 字体、颜色、间距和手机布局统一修改 `static/css/style.css`，两种语言共用，不需要分别修改样式。
- 两页的章节 ID 相同。修改页面结构时同步调整对应 HTML。
- 用浏览器打开根目录 `index.html`，点击 English 进入英文主页，点击中文返回。禁用 JavaScript 也能阅读和切换语言。
- 两页有各自的 `lang`、标题和 `hreflang` 替代页链接，英文内容直接写在 HTML 中。
- 右上角只保留一个“主题”按钮，点击打开主题面板。面板中提供“跟随系统／浅色／深色／蓝色／青色／绿色／紫色／橙色／自定义”九个选项，每项有颜色预览。首次访问默认跟随系统；选择后会记住偏好。在同源网站中，中英文页和已打开的其他标签页共用偏好。
- 主题在样式加载前初始化，减少深色页面的白色闪屏。浏览器禁用本地存储时仍可使用主题菜单，但无法记住选择。
- 每个主题都是独立的整页外观，背景、导航栏、边框、按钮和链接一起变化。浅色为白底，深色为深底，五种彩色主题各有固定配色，不再叠加明暗选项。
- 五个彩色预设分别提供对应色调的正文、标题和辅助文字颜色，例如蓝色为深蓝正文、绿色为深绿正文；不再共用同一正文色。自定义模式下，正文和非链接标题直接采用所选的“文字颜色”。
- 可点击跳转的文字（包括论文标题和“论文 / Paper”入口）统一使用主题的链接颜色；论文入口悬停时也保留此颜色。选择自定义时，可用“链接颜色”单独设置这些文字。
- 只有“跟随系统”会根据电脑设置在浅色与深色之间切换；选定任何其他主题后，不受系统明暗变化影响。
- 在同一面板中选择“自定义”，即可设置背景、文字和链接颜色，无需额外的调色入口。修改立即显示，“恢复默认颜色”只重置自定义颜色，切换到其他主题不会丢失已保存的自定义颜色。
- 顶栏采用紧凑的全宽排版，六个导航贴近窗口左侧，语言和主题按钮贴近右侧。小屏幕上导航可横向滚动。导航栏、语言按钮、主题按钮和面板都共用整页的背景、文字和边框变量，随页面主题同步变化。
- 点击“完成”、关闭按钮、面板外部或按 Esc 可收起面板。键盘可通过 Tab 和方向键选择主题，Esc 和完成会将焦点返回主题按钮。
- 自定义颜色仅保存在当前浏览器中，不会改写网站文件或其他访客的设置。刷新或在同源网站中切换语言会恢复自己的颜色；不需要翻译接口或后端。

中文页的语言链接：

```html
<a href="en/index.html" lang="en" hreflang="en">English</a>
```

英文页的返回链接：

```html
<a href="../index.html" lang="zh-CN" hreflang="zh-CN">中文</a>
```

## 图片、论文与链接

图片统一放在 `static/images/`。中文页使用 `static/images/...`，英文页使用 `../static/images/...`。

论文动图为 `paper-1-preview.gif` 至 `paper-4-preview.gif`，通过 `<img>` 显示。论文题名、作者、期刊和编号保留原文。新增论文或动态时，在两页对应章节分别添加一条记录即可。

第一篇论文入口为 https://trid.trb.org/View/2425132 ，是含摘要、作者与期刊信息的记录页，不提供全文。

中英文页的 GitHub 图标均链接到 https://github.com/ICV-WTU ，点击后在新标签页打开账号主页。

## 发布

项目仓库：https://github.com/ICV-WTU/cj-page

网页位于仓库的 `teacher-homepage/` 子目录，仓库根目录保留原主页。

GitHub Pages 访问地址：

- 中文：https://icv-wtu.github.io/cj-page/teacher-homepage/
- 英文：https://icv-wtu.github.io/cj-page/teacher-homepage/en/

Pages 使用 `cj-page` 仓库的 `main` 分支根目录发布，当前网页作为其中的子目录站点。网页本身无需构建，中英文页面和图片均使用相对路径，兼容 `teacher-homepage/` 子目录。

修改本地网页后，将以下文件同步到 `cj-page` 仓库的 `teacher-homepage/` 目录，提交并推送至该仓库的 `main` 分支即可触发重新发布：

```text
teacher-homepage/
├── index.html
├── en/
├── static/
├── README.md
├── LINKS.md
└── .nojekyll
```

之前的中文源文件生成流程、翻译缓存、API 接入脚本和 `dist` 目录已移除。当前两页就是最终网页文件，无需翻译 API 或后端。
